# AMD then Apple native GPU lab implementation plan

> Inline implementation by Hermes. User explicitly requires personal implementation, AMD before Apple, all first-party code in seeded Omega, Wolfram for calculations. No subagents.

## Goal and scope
Start real machine-code generation and virtual execution for AMD gfx1100 (RDNA3), followed by Apple G13/G14 AGX. Produce bounded integer matrix-vector kernels as an inference building block. This is an explicit lab target, not a hardware launcher, complete inference engine or performance simulator. No GPU access, driver changes, firmware changes or serving changes.

## Architecture and constraints
All generators, instruction interpreters, fixture generation, validation, and test logic are handwritten .om compiled by the qualified seed-native compiler (SHA256 191b776ef98821597c3e30655da6d680a9b66edbc9ceaca3c39c61ea6df098e9). Shell/Git/SSH are host transport/build glue only. No first-party C, Rust, Python, Metal or Vulkan runtime. LLVM is an external AMD instruction oracle, not the emitter. Prior AGX C tables and recorded Apple machine-code corpus are reference data only, never compiled or linked.

The kernel computes signed-int8-valued matrix/vector products in sign-extended 32-bit storage, with 32-bit accumulation. K=1..64, rows=1..32. This does not implement packed-int8 tensor-core inference. Wolfram establishes bounds and independent fixtures. Simulator decodes emitted instruction bytes, tracks pending loads, refuses use-before-wait, checks memory bounds and target/opcode legality, and stages output until success. Unsupported formats fail closed, not fallback.

## Files and tasks
1. `native/gpulab/common.om`: bounded code/virtual-memory/register storage, exact byte helpers, transactional result publication. `native/gpulab/amd.om`: gfx1100 emit and interpret supported load/wait/mul/add/store/end. `native/gpulab/test-amd.om`: independent scalar oracle, frozen LLVM bytes, signed extremes, all depth/row boundaries, mask/tail checks, malformed/unknown programs, omission/order mutants. Observe compilable refusal stub RED, implement, execute GREEN, commit.
2. `native/gpulab/agx.om`: AGX emitter/interpreter for equivalent load/wait/integer ALU/store/stop. `native/gpulab/test-agx.om`: freeze known reference instruction bytes and operand boundaries, scalar/memory/negative tests. Observe RED before implementation; AMD gates remain green.
3. `native/gpulab/emit-main.om`: bounded target/depth request on stdin, raw generated bytes only on complete validation. Tests written in Omega. Build and source/provenance instructions in `native/gpulab/README.md`, raw receipts in `evidence/NATIVE-GPULAB-L617/`. Freeze committed source, rebuild/replay in fresh output space and publish branch, never merge.

## Review focus
- Unsupported target/generation must not silently map to supported hardware.
- Bad offset, truncated instruction, missing wait/stop, invalid register must refuse without committing results.
- Signed values, wraparound, partial waves, maximum depth must agree with independent numerical fixtures.
- Simulators must decode actual bytes, not call the original algorithm instead.
- All result labels distinguish lab ISA subset, simulator correctness, hardware qualification, and speed. Author review only under personal-work direction; independent review is not claimed.
