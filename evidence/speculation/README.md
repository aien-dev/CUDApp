# Native component evidence

This receipt qualifies bounded host components for #63 through #66. It does not
qualify a model adapter, GPU execution, real timing, or a performance claim.
All physical 27B comparison trials are **NOT_RUN**. The issues remain open.

The tested source is `9ff84f025ee1b333365a3d95e487240e086d4991`.
The following evidence-only commit does not change its implementation or tests.
[receipt.json](receipt.json) contains ordered source inputs, source and executable
SHA-256 values, exact test outputs, and each behavioral control's literal edit.
[Reconstruction instructions](../../docs/speculation/REPRODUCE.md) pin the
compiler source, seed input and reconstructed compiler bytes.

The oracle uses a separately expressed two-outcome drafter expectation and
compares selection over probability, cost, memory and remaining-budget grids.
It is synthetic evidence, not a measured acceptance distribution.

The eight behavioral controls force ordinary selection, omit epoch checks,
admit incomplete rounds, count an unconsumed token as consumed, discard host
overhead, ignore differing outputs, accept the wrong arm build, and overclaim
a finite confidence interval with five pairs. Compile failures, crashes and
timeouts are excluded from this count.

The checked-in `synthetic-*.bin` and `.reply` files are generated by the native
fixture program and consumed by the native replay and reply verifier. Every
record remains explicitly synthetic. They contain no model weights, private
prompts, machine configuration or actual performance observations.

`readelf -l` found only two load segments and no interpreter or dynamic segment
in the replay executable. `strace` of the policy test observed only stdout
writes and exit after process startup. The replay observed stdin reads, one
stdout write and exit; its output was byte-identical to the retained reply.
This is bounded execution evidence, not proof about every possible input.
Raw local build, regression and syscall logs remain outside the repository.

The legacy regression command was
`quiet-build make -j2 OUT_DIR=build/regression test`. Its result was
`CUDA++ HOST TESTS PASS (33 targets)`. Those tests exercise the existing C++ host
implementation and are reported separately from the new seeded `.om` tests.

Development tooling included existing shell bootstrap, Git, Node.js orchestration,
readelf and strace. None is linked into, called by, or shipped as the runtime
implementation. No Python was used. An earlier exploratory source used a
reserved identifier and failed compilation; it was corrected before the frozen
source qualification above. An initial output-bypass control also failed to
compile and was replaced with a compiling comparison bypass. Neither compiler
failure is counted as passing evidence.
